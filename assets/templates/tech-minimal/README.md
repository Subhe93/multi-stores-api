# tech-minimal — bundled kit assets

Drop the kit's images here using the **exact filenames** referenced in
`src/modules/templates/kits/tech-minimal.ts` (the `assets` map). Missing files
fall back to a generated gradient SVG placeholder, so the kit always renders.
See `../shoes-modern/README.md` for the full pipeline notes.

Expected files:

| key | file | used by |
|-----|------|---------|
| preview | `preview.jpg` | gallery card thumbnail |
| hero-1 | `hero-1.jpg` | hero-slider |
| gadget-1 … gadget-4 | `gadget-*.jpg` | demo products (Phase 5) |
| testi-1 / testi-2 | `testi-*.jpg` | testimonials avatars |
